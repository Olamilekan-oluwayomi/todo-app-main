## Overview

### The challenge

Users should be able to:

- View the optimal layout for the app depending on their device's screen size
- See hover states for all interactive elements on the page
- Add new todos to the list
- Mark todos as complete
- Delete todos from the list
- Filter by all/active/complete todos
- Clear all completed todos
- Toggle light and dark mode

## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- Mobile-first workflow
- Vanilla JavaScript (ES6+)
- LocalStorage for theme preference

### What I learned

During this project, I improved my Vanilla JavaScript skills by implementing a robust state management system, handling dynamic DOM updates effectively, and working closely with local storage to persist the user's preferred theme. I also reinforced my CSS skills using Flexbox and responsive design principles.

### Continued development

I want to continue focusing on more complex state management in Vanilla JS without frameworks. Furthermore, implementing the drag and drop feature for reordering list items would be an excellent future addition to this project.
